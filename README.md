# app-mobile-ui

React Native mobile application for LOFYD, built with Expo. Runs on iOS and Android.

## Prerequisites

- [Node.js](https://nodejs.org/) >= 18
- [Expo CLI](https://docs.expo.dev/get-started/installation/)
- [iOS Simulator](https://docs.expo.dev/workflow/ios-simulator/) or [Android Emulator](https://docs.expo.dev/workflow/android-studio-emulator/) (for local development)

## Installation

```bash
npm install
```

## Usage

### Run Locally

```bash
npx expo start
```

Then press `i` to open in the iOS simulator, `a` for Android emulator, or scan the QR code with [Expo Go](https://expo.dev/go) on your device.

### Run on iOS

```bash
npx expo run:ios
```

### Run on Android

```bash
npx expo run:android
```
